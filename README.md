# Nexify Technologia Ltd.

> A modern software company portfolio website built to showcase Nexify's services, projects, expertise, and digital solutions.

## Live Demo

**Live Website:** https://nexify-technology.netlify.app

**Source Code:** https://github.com/pollobdebnath18/Nexify

## Overview

Nexify Technologia Ltd. is a software and technology company that provides modern digital solutions for schools, colleges, businesses, startups, and organizations. This website was built to present the company's identity, services, work, and process in a clear and professional way. Visitors can explore the company introduction, the services offered, a selection of projects, the working process, and a contact page to get in touch. It is intended for potential clients, recruiters, and anyone interested in Nexify's work.

## Key Features

- Responsive design across all screen sizes

- Project / portfolio showcase

## Project Structure

```text
src/
├── app/
│   ├── about/        # About page
│   ├── contact/      # Contact page
│   ├── services/     # Services page
│   ├── globals.css   # Global styles
│   ├── layout.js     # Root layout
│   └── page.js       # Home page
├── components/       # Reusable UI components
├── images/           # Static images
public/               # Public assets
```

- `src/app/` — Application routes built with the Next.js App Router.
- `src/components/` — Reusable sections and UI components (navbar, hero, sections, footer, etc.).

## Getting Started

```bash
git clone https://github.com/pollobdebnath18/Nexify.git
cd Nexify
npm install
npm run dev
```

Open http://localhost:3000 in your browser to view the application.

## Available Scripts

```bash
npm run dev    # Start the development server
npm run build  # Build the application for production
npm run start  # Start the production server
npm run lint   # Run ESLint
```
